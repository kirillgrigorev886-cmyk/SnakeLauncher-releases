# SnakeLauncher

Официальные установщики SnakeLauncher для Windows 10/11 x64 и подписанные метаданные обновлений.

[Скачать последнюю версию](https://github.com/kirillgrigorev886-cmyk/SnakeLauncher-releases/releases/latest)

Установщик создаёт ярлыки на рабочем столе и в меню «Пуск». Приложение и настройки находятся в `%APPDATA%\!SnakeLauncher`, Minecraft — отдельно в `%APPDATA%\!minecraft`. Каждая сборка имеет собственную игровую папку в `versions`.

Начиная с версии 1.0.3, лаунчер проверяет обновления при запуске и загружает их в фоне. Установка выполняется при безопасном закрытии, когда Minecraft завершён и операции с файлами закончены. Настройки, сборки и миры сохраняются при обновлении и удалении приложения. Для перехода со старой версии без автообновления один раз запустите актуальный установщик вручную.

Установщик пока не имеет сертификата издателя Windows. Канал автоматических обновлений защищён проверкой SHA-512 и подписью Ed25519.

Этот репозиторий содержит только установщики и файлы обновлений. Исходный код и закрытые ключи здесь не публикуются.
